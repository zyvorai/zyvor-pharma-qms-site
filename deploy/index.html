Deploy

Four ways to run it.

Same pilot stack on Mac FluxVM, Linux compose, k3s/Helm, or Windows Docker Desktop / WSL.

Mac · FluxVM

make deploy-fluxvm or the FluxVM helper in the product deploy tree. Compose fallback if the VM control plane is offline.

Linux · Compose

Podman or Docker Compose: Postgres, API and UI. One command up.

Kubernetes · k3s

Helm chart and raw manifests for API, UI and Postgres. Import local images for air-gapped labs.

Windows

Docker Desktop compose, or WSL2 running the Linux compose script.

Application images and installers are not published in this website repository. Ask sales for evaluator access.
