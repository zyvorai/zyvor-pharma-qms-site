Security

What we built — and have not claimed.

Controls in the pilot product, stated plainly. Not a penetration-test report.

Actor identity

Writes carry actor username, display name and role headers; audit events record who did what.

Role gates

Quality and laboratory actions refuse wrong roles. Admin bypasses for evaluation convenience.

Tamper-evident audit

Application-level audit log in a verifiable hash chain, with review-by-exception and CSV export. Tamper-evident, not a claim of tamper-proof storage.

Authentication and signatures

Strict mode: argon2id password login, optional TOTP, server-side sessions, API keys stored hashed, and password re-entry for approvals. Default demo mode trusts identity headers and must not hold real records. No SSO yet.

Honest banners

UI and API meta state that the system is not validated and not Part 11.

  • No independent penetration test.
  • No SOC 2 / ISO 27001 / Part 11 certification.
  • Passwords and full IAM are evaluation-grade actor switching, not enterprise SSO yet.
