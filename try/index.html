Native apps

Double-click to start the pilot.

Built from the product desktop packagers. Needs Podman or Docker Desktop for Postgres (or any Postgres on :5432).

macOS

PharmaQMS.app — builds with make desktop-macos in the product tree, or download from the latest site release when published.

Apple Silicon and Intel. Opens http://127.0.0.1:8080

Windows

PharmaQMS.exe + Start-PharmaQMS.bat — build with pwsh desktop/windows/build.ps1, or take the release zip.

Docker Desktop recommended. Opens http://127.0.0.1:8080

One-line install

Pick your computer.

Same pattern as other Zyvor product sites. The installer writes under ~/.zyvor-pharma-qms and verifies the checksum.

Mac

Open Terminal, paste, press Return. Requires a published release bundle.

curl -fsSL https://github.com/zyvorai/zyvor-pharma-qms-site/releases/latest/download/get.sh | sh -s -- up

Windows

Open PowerShell. Docker Desktop or WSL2 recommended.

& ([scriptblock]::Create((irm https://github.com/zyvorai/zyvor-pharma-qms-site/releases/latest/download/get.ps1))) up

Linux

Open a terminal, paste, press Enter.

curl -fsSL https://github.com/zyvorai/zyvor-pharma-qms-site/releases/latest/download/get.sh | sh -s -- up

Until the first release ships the tarball, clone the private product repo and run make desktop / make desktop-macos.

Check

Did it work?

  1. Health. curl -sf http://127.0.0.1:8080/healthz should return ok.
  2. Features. Open /api/v1/features — you should see 50+ modules.
  3. Console. Open the UI, switch actor to qa, create a batch, walk laboratory → approve.
  4. Stop. Quit the app, or run the installer down command.
