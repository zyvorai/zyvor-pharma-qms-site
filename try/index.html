One-line install

Pick your computer.

The installer scripts expect a release bundle on this site's Releases page. None is published yet, so these commands will not work today; they are shown for when one is. Bundles are available on request. The installer writes under ~/.zyvor-pharma-qms and verifies the checksum.

Mac

Open Terminal, paste, press Return. Needs a published release bundle (none yet).

curl -fsSL https://github.com/zyvorai/zyvor-pharma-qms-site/releases/latest/download/get.sh | sh -s -- up

Windows

Open PowerShell. Docker Desktop or WSL2 recommended.

& ([scriptblock]::Create((irm https://github.com/zyvorai/zyvor-pharma-qms-site/releases/latest/download/get.ps1))) up

Linux

Open a terminal, paste, press Enter.

curl -fsSL https://github.com/zyvorai/zyvor-pharma-qms-site/releases/latest/download/get.sh | sh -s -- up

The product source is private. Until a bundle is published, ask us for an evaluation bundle.

Check

Did the local install work?

  1. Health. curl -sf http://127.0.0.1:8080/healthz should return ok.
  2. Features. Open /api/v1/features — you should see 84 catalogue entries (73 modules and 11 AI assistants) plus a maturity map of pilot and partial entries.
  3. Console. Open the UI, switch actor to qa, create a batch, walk laboratory → approve. A local install starts in dev mode, which trusts identity headers: keep it on your own machine, and use strict mode for anything others can reach.
  4. Stop. Quit the app, or run the installer down command.
